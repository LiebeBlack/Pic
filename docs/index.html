Características premium

Todo lo que un visor de fotos debería ser

Una interfaz acrílica moderna sobre un motor de imagen serio: calidad de estudio con el tacto y la velocidad de una app nativa.

🎨

Interfaz Glassmorphism

Estética acrílica inspirada en Windows 11 con dock flotante compacto, tema claro/oscuro automático según el sistema y ventana redondeada.

🖥️

Renderizado GPU Direct2D

Escena dibujada por hardware a 60 FPS con CPU ~0%. Si Direct2D no está disponible, se vuelca automáticamente al trazador GDI+ clásico.

🔍

Zoom píxel-perfecto

Auto-snap a 100%, 200%… con interpolación de vecino más próximo (nitidez cristalina) y bicúbica fotográfica de alta precisión en escalas intermedias. Hasta 200×.

✨

Ultra-Claridad HDR

Modo de realce de micro-contraste y detalles finos, horneado una sola vez por cambio — cero coste por fotograma.

🧊

Transparencia clara

Fondo ajedrezado inteligente (una sola llamada de textura en vez de miles de rectángulos) para PNG, WebP, ICO y GIF.

📷

EXIF automático

Detecta y corrige la orientación de fotos de móviles y cámaras, con panel de propiedades y metadatos integrado.

🎞️

GIF animados fluidos

Sincronización proporcional al tiempo transcurrido: si el sistema va retrasado se saltan fotogramas para no perder el ritmo.

🧠

Caché LRU inteligente

Prefetch en segundo plano a prioridad mínima, presupuesto de caché ajustado y devolución de RAM al sistema tras cada carga (Working Set Trim).

🖱️

Navegación avanzada

Flechas para imágenes y zoom, arrastre para panorámica, rueda centrada en el cursor, botones X1/X2 del ratón y dock con atajos de un clic.

🖼️

Fondo y portapapeles

Establece la imagen como fondo de escritorio con un atajo y copia al portapapeles en calidad máxima (exportación 100%).

📤

Guardar / exportar

Exporta con rotación y volteos aplicados a PNG, JPEG (calidad 100%) o BMP mediante el diálogo nativo de Windows.

🛡️

Ligero por diseño

Arrastra y suelta, línea de comandos, presentación F5, pantalla completa F11 y arranque instantáneo. Sin telemetría, sin servicios en segundo plano.

Rápido de verdad, no solo de apariencia

💾

Memoria durante la navegación

Caché compacta de 4 imágenes con tope de 64 MB, sin copias duplicadas al rotar o voltear.

⚡

CPU en reposo y al mover el ratón

El dock y el OSD repintan solo su banda; el fotograma 4K no se vuelve a escalar en cada hover.

🎞️

Reproducción GIF animado

Avance por temporizador con salto de fotogramas atrasados y subida al GPU solo cuando cambia el contenido.

Motor de imagen

Tres decodificadores, uno superior

El código elige el mejor motor para cada archivo — calidad sin concesiones con el mínimo coste.

GPU

Direct2D + DirectWrite

Escena completa (foto, ajedrez, OSD, dock) por hardware. Interpolación lineal GPU con bloqueos al mínimo en reposo.

CPU

GDI+ con trazado optimizado

Respaldo automático (o forzable con ARTPICST_NO_GPU=1) con repintado parcial, bicúbica solo al ampliar y patrón de transparencia en una llamada.

📂

Decodificadores stb_image / WIC / GDI+

stb para los formatos ligeros, Windows Imaging Component para WebP/HEIC/RAW y GDI+ para metarchivos. Decodificación en el hilo justo y prefetch a prioridad mínima.

Formatos soportados

30+ formatos, sin complementos

Cada formato se enruta al motor que mejor lo decodifica, con límite de dimensiones para mantener la RAM contenida.

stb_image: JPG · PNG · BMP · GIF · TGA · PSD · HDR · PIC · PNM/PPM/PGM WIC (Windows): TIFF · ICO · WebP · HEIC/HEIF · AVIF · JPEG-XR/WDP WIC RAW: CR2 · NEF · ARW · DNG · y otros RAW de cámaras GDI+: TIFF · EMF · WMF · códecs del sistema

Requisitos

Windows 10 / 11

Sistema operativo de destino. La app detecta el tema claro/oscuro y escala por DPI del monitor.

Visual Studio 2019/2022+ con escritorio en C++

O MinGW-w64 como alternativa. También se ofrece un CMakeLists.txt para otros flujos.

Git

Para clonar el repositorio: git clone https://github.com/LiebeBlack/Pic

Build en tres sabores

Compilación de un toque

Cualquiera de estos comandos produce artpicst.exe y artpicst_installer.exe en dist\:

# Opción 1 — PowerShell (recomendada)
powershell -ExecutionPolicy Bypass -File build.ps1
# Opción 2 — Batch
build.bat

# Opción 3 — MinGW
build_mingw.bat

Cada ejecución compila el visor, el instalador premium y copia icono y versión a dist\. En CI (GitHub Actions) se compila automáticamente en cada push.

Línea de comandos

Integra ARTPICST en tu flujo

# Abre el visor, una carpeta o una imagen concreta
artpicst.exe
artpicst.exe "C:\Fotos"
artpicst.exe "C:\Fotos\imagen.jpg"

# Modos de ventana y registro del instalador
artpicst.exe --maximized "C:\Fotos"
artpicst.exe --fullscreen "C:\Fotos"
artpicst.exe --register
artpicst.exe --unregister

Preguntas frecuentes

Soporte y dudas habituales

¿Algo no funciona? Abre un issue en GitHub con el error y el paso a paso; la respuesta suele llegar en horas.

¿Es realmente gratis?

Sí. ARTPICST es gratuito y de código abierto: úsalo, cópialo y modifícalo libremente para fines personales. No está permitida su venta ni su redistribución comercial sin autorización previa.

¿Necesito permisos de administrador para instalarlo?

No. El instalador trabaja por usuario en %LOCALAPPDATA%\Programs\ARTPICST, sin elevación UAC. Es ideal para equipos corporativos o cuentas sin derechos de administrador.

Mi equipo no tiene GPU. ¿Funcionará igual?

Sí. Si Direct2D no está disponible, el visor usa automáticamente el trazador GDI+ optimizado (repintado parcial, patrones en una sola llamada). También puedes forzarlo con la variable de entorno ARTPICST_NO_GPU=1.

¿Puedo abrir fotos RAW de mi cámara?

Sí: CR2, NEF, ARW, DNG y otros RAW se decodifican a través de Windows Imaging Component. El soporte depende de los códecs WIC instalados en tu Windows (los de tu marca de cámara si el RAW no está cubierto por defecto).

¿Cómo desinstalo ARTPICST?

Abre Menú Inicio → ARTPICST → Desinstalar ARTPICST, o ejecuta artpicst_installer.exe --unregister. Se eliminan archivos, accesos directos y asociaciones de archivo.

¿Se guarda mi configuración en la nube?

No. ARTPICST no tiene telemetría, no crea cuentas ni envía datos a ningún servidor: al abrirlo solo lee la carpeta que le indiques y sigue el tema claro/oscuro de Windows.
